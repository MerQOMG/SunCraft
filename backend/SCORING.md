# 光热舒适评分与前端联调

## 读取报告

普通和精简模拟都返回 `score_report`。寻优的 `before.score_report` 与 `after.score_report` 用同一函数计算。请求 `include_simulation=true` 时，`simulation.score_report` 与 `after.score_report` 相同。无可行解时保留当前报告，`after` 为空。

| 界面 | 数据来源 |
| --- | --- |
| 总分环和等级标签 | `total_score`（展示时保留一位小数）、`grade`、`grade_label` |
| 四个维度条 | 遍历 `dimensions`，用 `name`、`score`、`weight` 绘图 |
| 指标行 | 遍历 `items`，使用 `name`、`value_display`、`threshold_display`、`score`、`max_score`、`status`、`citation`。`value` 提供未按显示格式舍入的物理量 |
| 依据标签 | `citation_type` 取 `project`（项目目标）、`reference`（参照文件）或 `mandatory_reference`（涉及强制性规范的项目筛查） |
| 空间联动 | `highlight_target="sofa"` 高亮沙发；`"winter_section"` 高亮冬季进深标注，其余为 null |
| 红线与提分按钮 | 遍历 `warnings[].key/message` 展示触发原因。用 `suggest_optimization` 控制提分按钮，点击后展示寻优实际达到的等级。页脚可直接使用 `methodology_note` |

## 分数如何得到

每项按下表的节点线性插值，两端截断。表内的百分数表示子项满分的比例。方案只给出及格门槛时，取该项分值的 60%。子项保留六位小数后累加。S 从 90 分起，A 从 80 分起，B 从 65 分起，其余为 C。提分提示在总分低于 85 时显示。

| --- | --- | --- |
| 夏季遮阳 35 | 夏季遮挡率（20） | 0.40 → 0%，0.90 → 100%。项目目标 0.85 |
| | 窗墙比和等效 SHGC（15） | WWR 0.45 → 100%、0.75 → 0%。SHGC 0.45 → 100%、0.55 → 0%。取两者较低值 |
| 冬季得热 25 | 冬季得热率（12） | 0.40 → 0%，0.80 → 100%。项目目标 0.75 |

## 物理口径

- **采光。** 地板划成 24 × 24 个等面积格。均匀度取同一 DF 矩阵的最小值除以平均值，全暗时取零。达标面积比为 DF ≥ 2% 的格数除以 576。窗地比取实际玻璃面积除以 5.4 × 6.0 m²。漫射模型使用均匀天空近似，无全年气象文件或 UDI/sDA 输入。
- **日照时数。** 采用当地真太阳时，每 15 分钟计算一次太阳方向。冬至日 08:00 到 16:00 共 33 点，夏至日全天共 97 点。对命中状态作梯形积分，起止时刻各计半个步长。背阳或太阳在地平线下均不计入。
- **满窗判据。** 整个玻璃开口须同时收到无遮挡直射。只要挑檐或叶片的投影有正面积，该时刻即不计入满窗时数。现有水平构件横跨窗宽，因此出现“冬季得热率较高、满窗时数为零”是模型可解释的结果。将 `louvers_enabled=false`、`overhang_depth_m=0` 即可复现真正的无遮阳基准。
- **沙发。** 平面占地取距窗 2.0–3.8 m、居中宽 2.2 m 的矩形，宽度是方案未指定时采用的假设。沿窗法向与横向都检查投影；只有穿过百叶实际间隙的光束与矩形有正面积交集，才累计时间。
- **等效 SHGC。** 展示值为 0.55 × (1 − 0.75 × 夏季正午遮挡率)。负荷比较使用同一个遮挡折减式，并按各时刻入射方向对立面的法向投影加权；冬季按透过的有效直射计得热。记夏、冬时段加权开口率为 U_s、U_w。采用上海方案的冷热季预算 C=0.70、H=0.30；某季全程无入射时该季预算取零。相对降幅为 0.55 × [0.75 C (1−U_s) − H (1−U_w)] / [0.55 C + 0.45 H]。分母为零时取零，损失可产生负降幅。它是同窗无遮阳基准下的相对指标。其他城市也沿用这套权重，年用电量、碳排量和 ±10% 精度均未经标定。

## 上海南向复现

使用默认纬度、朝向、窗墙比 0.50，以下数值显示到两位小数。

| 场景 | 挑檐深度 | 百叶 | 总分 | 等级 |
| --- | ---: | --- | ---: | --- |
| 无遮阳 | 0 m | 收起 | 57.81 | C |
| 过度遮阳 | 1.60 m | 75° | 69.28 | B |
| 对默认设计执行寻优 | 0 m | 启用，0° | 92.31 | S |

最优方案的冬季进深约 2.92 m，固定叶片仍触发满窗警示。不同朝向、纬度或窗墙比可产生其他等级；采光约束无法满足时返回 `infeasible`。

## 无夏季正面入射的工况适用性

当夏至正午太阳在立面背后或与窗面平行时，物理遮挡率仍返回 0、summer_incident=false，代表射线为空。评分将遮阳目标按无直射风险已满足处理；WWR/SHGC 项保留窗墙比筛查，不把材料 SHGC 改成 0，也不据此认定规范豁免。此适用性标记由同一性能值同时传入模拟与向量化寻优，本地引擎采用相同处理。广州南窗等工况的报告与警示会明确说明原因。
