# R2 / 建筑日照研究台 — 首轮实现，待浏览器实看

方向：纸白/石墨/矿物棕，清晰、可读的建筑图板，不采用绿色毛玻璃卡片叠加的后台语言。模型获得独立舞台，控件退到细边框侧栏；字体使用系统无衬线，数字等宽，季节/图例/设计单共用色标。

基线最大问题（代码审查及前轮截图）：
1. 模型被高机位压成小型玩具；通体高强度填光，木材偏橙且家具错误共用拼板纹理，叶片是椭球薄饼。
2. 剖切移除屋顶后直射光从顶部灌入，遮阳不具备可信表现；太阳 X=-.4 使正午高度/方位不精确；广州夏至太阳在北侧，旧代码仍放在南侧。
3. SVG 冬季射线直接连向启发式得热率折减的深度，角度不再符合标注。外部入射段也未与内部共线。
4. 字太小、低对比、诗意标题和装饰比真实状态抢眼；侧卡占据模型投影空间。

本轮：共享太阳向量与剖面几何，补不可见但投影的屋顶/剖切墙；保留正午条件，上海82.24°/35.36°，不伪造深射夏季光；DF及优化算法和接口保持不变。模型换可信木板尺度、独立胡桃木纹/细织物凹凸、软包滚边、垂布、薄叶及枝干；低机位自适应构图、真实方向阴影、窗外低对比树/建筑背景（仅情境背景，不投影）。

验证边界：本执行无浏览器权限，不运行Playwright替代；只做类型/构建/纯数学及契约测试。开发服务器留给主任务用浏览器实看并截图，再依据最大问题继续迭代。尚未认定视觉完成。
