# P2 / 窗光—首反射—阴面的层次，待标准浏览器复看

## 根因与取舍

原可见天花复用了墙漆，但主要间接光来自低强度RoomEnvironment、棕色下半球和无阴影的固定方向补光；真实直射只能照到一部分地面，WebGL并不会自动把这部分能量反弹到天花。结果顶面向下法线收到偏暗偏棕的环境项，形成整块灰板，其余物体又被均匀填平。继续简单抬高同一个ambient会冲淡冬季真实光带，不建立空间层次。

### 1. 让漫射光有来源和距离

- 删除棕色HemisphereLight和固定无阴影Directional补光，降低通用RoomEnvironment强度至.10，只保留少量材质反射背景。
- 用匹配实际窗洞尺寸的LTC矩形面光近似窗洞漫射入射：位置在窗内、朝室内，不是窗外图片，不画可见发光卡片。近窗与进深处按面光源几何自然衰减。
- 面光强度跟随窗洞面积和整体天空可见度。768条确定性半球采样核对挑檐、7片百叶、实体屋顶、窗墙厚度、框/梃和窗台遮挡，不用固定亮度纹理冒充光照。
- 新回归曾发现只查窗内洞口会让极少数夏季高角度光线在预算里误通过；现补齐160mm外墙与上口厚度，夏季默认直射首反射输入为0，未为戏剧性编造夏季深射。

### 2. 近似室内首反射，不给天花自发光

- 增加由窗洞输入预算驱动的地板向上漫反射、北墙回返两个宽面光。反射份额和材料反射率有界；冬季地板额外首反射仅来自家具外的粗采样真实直射可达区域。
- 天花改为高反射率哑光白涂层，与略暖墙面区分；无emissive、无假天窗，实体屋顶与castShadow保持。
- 全季节固定曝光1.10，显示日光色温近似夏6000K/冬5200K；天空漫射采用7500K。无季节暗滤镜或自动曝光制造反差；太阳高度、方位和既有直射强度未改。

**边界必须明确**：这些相对渲染强度没有lux或实测光谱标定；LTC窗洞把方向天空/外部地面漫射合并近似，RectAreaLight本身不投射遮挡阴影，家具间的漫射传递并非真实GI。整体窗洞可见度、有限首反射预算与接触AO只能改善表现，不能代替物理引擎。它们不输入DF、遮阳率、优化或SVG指标。真正季节光带仍只由原Directional太阳和实体shadowMap产生。

### 3. 接触层次来自几何，不是屏幕暗角

- 加入基于实际深度/法线的GTAO，世界空间半径140mm、混合强度.32，限于接触尺度；没有径向暗角、预绘脚底黑贴片或假太阳投影。
- G-buffer专门排除只投影不可见代理、玻璃、透明热力层和外部ShadowMaterial，防止剖切屋顶/北墙在AO中错误变成遮住整幅画的实体。
- 透明底色保留，最终统一经过OutputPass进行ACES与显示色彩转换，不重复色调映射。热力模式关闭接触AO，避免用AO再修饰热力颜色。
- AO缓冲最长边900px、12采样/8采样降噪；主画面仍保留DPR上限1.65和最多2倍MSAA，AO降采样不把主画面降成900px。仍按需渲染，不连续重算静止画面。
- 不支持浮点颜色附件时保留直接渲染路径；AO资源、深度纹理和composer在卸载时释放。没有FPS承诺，GPU真实成本仍须浏览器检查。

### 4. 毯子只做小范围真实曲面调整

保留P1贴坐面—圆弧转折—自由垂落结构，将相同正弦褶换成两道不等深、略偏斜的褶峰，增加垂落段轻微弧度和不齐下摆；不改变沙发/桌/地毯轮廓或布局。原布面接触与连续性测试仍通过。这仍是手工几何，不宣称布料动力仿真。
