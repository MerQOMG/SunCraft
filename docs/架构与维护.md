# 架构与维护

## 数据流

`App.tsx` 管理设计参数与连接模式，通过 `hooks/useSimulation.ts` 调用 `api.ts`。本地模式使用 `localEngine.ts`；FastAPI 模式请求后端。场景、指标、评分报告和导出使用对应方案的同一份结果，参数更新时旧结果标记为仅供对照，迟到请求不能覆盖新方案。

`components/Scene.tsx` 负责三维显示，`components/Section.tsx` 负责剖面，`components/AnnualTimeline.tsx` 负责日期预览。家具与窗细节在 `modeling/`，评分界面在 `scoring/`。固定示例与旧接口数据只在 `tests/fixtures/`，不参与生产计算。

## 评分与模型

`backend/suncraft/scoring_engine.py` 是评分规则的拥有方。`backend/export_client_reference.py` 导出 `src/scoring/rules.json` 和 `tests/fixtures/backend-scoring-reference.json`。前端本地计算以 48 组模拟基准和 4 组寻优基准核对后端，包括总分、十项贡献、等级、采光与遮阳指标、参数边界和不可行处理。

上海默认方案（0.40 m 挑檐、0° 百叶、45% 窗墙比）显示 91.1 分；挑檐改为 0 m 后为 94.4 分；1.80 m 挑檐、80° 百叶和 65% 窗墙比为 67.3 分。评分采用冬夏设计工况，日期轴改变几何预览与日期光照热力图；全阴天 DF 和方案评分仍独立于所选日期。解析几何、DF 和相对负荷模型的详细适用范围见后端说明。

## 入口与产物

只保留根目录 `夏遮冬透.html` 作为离线成品。默认浏览器、5175 HTTP 预览和后端同源页面共用它，避免不同入口版本不一致。`npm run build:offline` 更新这个文件；`dist/` 为可再生成的生产构建。

开发服务固定使用前端 5174、后端 8001。Windows 启动器会检查两项服务，并在退出时清理它启动的进程。仅环境检查可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-dev.ps1 -CheckOnly`。

## 检查

前端有单元、模型对照和浏览器回归；后端有 API、几何、评分与寻优测试。命令见根 README。`npm run format` 与 `format:check` 使用仓库内固定版本的 Prettier。测试不会修改历史资料，浏览器截图与下载只写 `前端文件/test-results/evidence/`。

## 日期光照与广州适用性修复（2026-11-28）

广州夏至正午南窗没有正面直射，原模型的物理遮挡率仍为 0；评分不再把它误当作遮阳失败。遮阳目标按无直射风险处理，SHGC 工况筛查保留窗墙比约束，材料 SHGC 数值不被伪改为 0。报告说明此处理不表示全年无需遮阳或规范豁免。默认广州方案由原来的 44.4 分变为 79.4 分；上海等有正面入射的工况保持原规则。模拟、寻优和本地报告均同步处理。

`src/solarAccess.ts` 提供与场景坐标一致的理想窗洞、挑檐和百叶遮挡判断，渲染光预算与日期热力共用它。`src/dateHeatmap.ts` 依所选日期的太阳方向，以每格 3×3 射线采样计算直射，再叠加原 DF 场的简化天空漫射项；超过 64×64 的输入作有限分辨率取样，防止大接口网格拖慢日期播放。

“日期光照”采用固定对数色标，范围 0–100；100 对应参考室外无遮挡太阳法向光强。玻璃直射透射率假设 0.72，天空漫射/法向直射参考比例假设 0.15，随太阳高度修正。它是明确假设下的相对光照近似，不是 lux、天气预测、家具遮挡或真实 GI。分数与全阴天 DF 不随播放日期伪造变化。“全阴天DF”模式保留 0–5% 原色标。

太阳方向沿用既有 NOAA/Meeus 日级真太阳正午模型；公式来源见 [NOAA 计算说明](https://gml.noaa.gov/grad/solcalc/calcdetails.html)。广州北侧太阳和近天顶情况不通过反转太阳、虚构直射或逐图拉伸色标来处理。

本轮验证：161 项前端测试、56 项后端测试通过；15 项浏览器回归覆盖广州、实时评分、日期热力与日期播放、DF 对照、导出、异常和离线入口，最终版额外复核了广州/日期热力/日期播放/窄屏四项。生产与离线构建通过。断网实测广州夏至直射面积比例为 0、相对光照均值约 0.75；冬至直射面积比例约 14.8%、相对均值约 7.85。两日期的方案工况评分均为 79.4，保持评分与日期预览的口径独立。
