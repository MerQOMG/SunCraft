## 4. 运行方式

当前开发运行只用仓库根目录的 `start-linked-dev.sh`，入口 **http://127.0.0.1:5174/**，后端 **127.0.0.1:8001**（`suncraft.demo:app`）。本盒上若服务已在跑，不要为打包去重启，也不要去清旧 5173。

在干净环境复现：

```sh
# 前端：在 前端文件 按上传原 lock 安装，不要改锁
cd 前端文件 && npm ci --ignore-scripts --no-audit --no-fund
# 后端：Python 3.10+，安装 backend/requirements.txt
# 然后在仓库根目录（端口 5174/8001 需空闲）
SUNCRAFT_PYTHON=/path/to/venv/bin/python ./start-linked-dev.sh
```

也可分两个终端：uvicorn 监听 127.0.0.1:8001，再在 `前端文件` 用 Vite `--host 127.0.0.1 --port 5174 --strictPort`。可用 `SUNCRAFT_API_TARGET` 配置代理。不要把 `suncraft.api:app` 原生引擎直接当成 Studio 前端契约。

源码包不含 `node_modules` 或 `dist`/`build`。移出本环境必须重新 `npm ci`，并自备已安装依赖的 Python。
