## 根因与修复
原ScoreDrawer的临时spatial在active改变时被清空，onHighlight又只允许score上下文；所以焦点离开原指标后切cases必定丢失。原指标卡也没有明确的激活导航命令。
- 新增独立inspection纯状态：瞬时hover/focus仍按原spatial机制；focus仅提供尚未激活的导航候选，不等于持久选择。hover本身绝不被锁定。
- 冬深卡自身Enter/Space，或原生“查看两至剖面”按钮（鼠标/键盘同命令），明确激活并进入工况。焦点随导航到工况面板；原指标变hidden/blur不再清除已激活选择。
- 从仍有指标焦点上下文直接激活“两至工况”页签，也会转交该候选。focus转到其他普通控件/画布指针操作/窗口失焦会忘记未激活候选，不把曾经hover过的指标永久锁住。页签方向键原行为保留，先切日期页会清除候选。
- 工况内显示“已定位：冬季阳光进深 / 清除定位”。清除后焦点留在工况面板，不随按钮卸载掉到body。切评分/日期、关闭、更新报告、pending变化或维度展开状态变化清除持久选择；仅日期播放不改变冬夏工况结果，亦不会冒称当日计算。
- 持久目标经原App highlight通道驱动原Section描边，未改深度、太阳或3.2px实际SVG标注；清除后回原虚线。App、Section、Scene、export、API、几何、日历和后端全未动。导出原先剔除分析标注的逻辑保持。
