- 广州无夏季正面入射时，图例与页面一致（夏季无正面入射，无夏至代表线），0% 遮阳须有适用性说明，不得写成普通遮阳不足或当天/全年性能。

- 离线全图栅格（Cairo/librsvg/Noto 或等价已装渲染器 + Noto）仅作矢量核对，不是 Chrome 全页预览。
