## 算法与数据来源、误差口径
自行用TypeScript实现NOAA/GML Julian-century/Meeus修正黄赤交角的太阳赤纬公开公式，不新增运行依赖，不做冬夏插值。
- https://gml.noaa.gov/grad/solcalc/main.js
- https://gml.noaa.gov/grad/solcalc/calcdetails.html
- 香港天文台2026官方年历：https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2026e.pdf
- 节气说明：https://www.hko.gov.hk/en/gts/astronomy/Solar_Term.htm

每日取当日UTC12赤纬作日级代表，时角H=0；高度=90°−|纬度−赤纬|，世界方向(0, cos(纬度−赤纬), −sin(纬度−赤纬))，保持既有南窗世界−Z定义。广州夏至太阳可在北侧，不为南窗硬造入射。
24节气使用**2026官方UTC+8日期表**而非永年固定表；不支持其他年份。
日级代表不是精密正午星历；未计折射/天气、未做实测误差验证。NOAA页面说明工具不再维护；其日出日落精度说明**不能当成本实现的阴影精度保证**。同一公式的±半日赤纬差本年最大约0.19775°，仅说明采样敏感性，不是实际角度误差上界，更不是室内阴影长度误差保证。
原始公开参考及年历归档在本目录，仅作出处备查，不在运行时加载整段参考JS。
